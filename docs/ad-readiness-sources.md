## Explicit project boundary

No advertising tag, CMP vendor, advertising cookie, or consent record is added by this release. The site receives a transparent, inactive readiness shell only. The site owner must supply an approved network account, publisher ID, configured CMP, and any required ownership or billing verification before ads can be activated.
